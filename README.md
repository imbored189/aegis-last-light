# AEGIS: Last Light

An original sci-fi campaign shooter for iPhone and other touch devices: ten missions across a ruined Earth, a derelict alien ark, a desert prison world and a frozen alien homeworld.

**Play:** open the GitHub Pages link for this repository in Safari on your iPhone, tap **Share → Add to Home Screen**, then launch AEGIS from the home-screen icon. It runs full-screen in landscape and works offline after the first load.
